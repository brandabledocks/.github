# Existing software. Your identity.

**brandabledocks** prepares custom-branded software packages on demand.

We build on software whose licenses permit the intended customization, pairing container builds with branding configuration and assets. The aim is to apply your identity without maintaining your own fork of the upstream project.

Packages are commercially supplied on request. Our packaging tools and customization repositories are private; upstream software retains its own license and attribution requirements.
